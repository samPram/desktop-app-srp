# Chart - Horsepower & Torque

## Desain
- Area grafik dengan latar hitam.
- Sumbu X: RPM (0 → 12,000).
- Sumbu Y: Power/Torque.
- Garis grid abu-abu tipis.

## Kurva
- **Horsepower (HP)**: garis merah.
- **Torque (Nm)**: garis biru.
- Keduanya meningkat seiring RPM, lalu melandai.

## Informasi Tambahan
- Legenda di dalam chart: `Horsepower` (merah), `Torque Torque` (biru).
- Titik data maksimum ditandai di bawah (lihat Peak Cards).
