# Sidebar - Menu Kiri

## Desain
- Panel vertikal di sisi kiri dengan latar warna gelap.
- Lebar sekitar 160px, tidak bisa di-resize (fixed width).
- Teks rata kiri dengan padding kecil.
- Font putih/abu-abu, ukuran sedang.

## Elemen Menu
1. Dashboard
2. Dyn Data
3. Cepols
4. Run History
5. Runs
6. Reports
7. Seports (kemungkinan typo dari "Reports")
8. Configuration

## Interaksi
- Setiap item menu berupa tombol.
- Hover: warna sedikit lebih terang.
- Klik: aktifkan halaman terkait (belum ada highlight aktif di gambar, bisa ditambah).
