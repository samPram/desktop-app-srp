# Gauges - RPM & Speed

## Desain
- Dua komponen gauge berbentuk lingkaran setengah (dial).
- Posisi: atas-tengah, sejajar horizontal.
- Ukuran: besar, menonjol.

## RPM Gauge
- Label: `RPM`
- Skala: 0 → 18 (x1000 rpm).
- Nilai ditampilkan: `6.85` (≈ 6850 rpm).
- Needle/indicator pada angka 7.
- Warna skala:
    - Normal: putih.
    - Redline mulai di angka 12 → 18 (warna merah).

## Speed Gauge
- Label: `Speed (km/h)`
- Skala: 0 → 300 km/h.
- Nilai ditampilkan: `95.2`.
- Needle/indicator pada angka ~95.
- Warna skala: putih.

## Interaksi
- Non-interaktif, hanya indikator real-time.
