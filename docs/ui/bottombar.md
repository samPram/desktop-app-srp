# Bottombar - Status Bar Bawah

## Desain
- Panel horizontal di bagian bawah window.
- Latar belakang abu-abu gelap.
- Teks rata kiri & kanan.

## Informasi Ditampilkan
- **Kiri**:
    - Status: `Connected to Dyno Hardware. Ready for test.`

- **Kanan** (dengan layout kanan-ke-kiri):
    - CPU: `15%`
    - RAM: `2.5GB`
    - Disk: `Disk 45GB Free`

## Interaksi
- Tidak interaktif, hanya indikator status.
