# Topbar - Judul Aplikasi

## Desain
- Panel horizontal di atas window.
- Latar belakang gelap polos.
- Teks judul rata tengah.

## Konten
- Judul: `MotoDyno v1.0.0`
- Posisi: tengah horizontal.
- Font: besar, tebal, putih.

## Interaksi
- Tidak ada tombol/menu di topbar (opsional bisa ditambah menu File/Settings seperti di gambar bagian atas).
